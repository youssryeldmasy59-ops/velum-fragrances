For the Founder

Shopify Free Theme Implementation

01

Best Free Theme: Dawn

Why Dawn? Shopify's own free flagship theme. Most flexible for custom HTML sections, full dark mode via color schemes, and zero paid-app dependencies. Alternative: Sense Cleaner card grid, great for product-forward dark layouts. Setup: Online Store → Themes → Explore Free Themes → Dawn → Add to Theme Library → Customize

02

Floating Rotating Logo

Step 1 — Add Custom Liquid section In Theme Editor → Add section → Custom Liquid. Paste your logo + animation wrapper HTML here. Step 2 — CSS in theme editor Go to: Edit Code → assets/base.css and add: .logo-spinner { animation: spin3d 11s linear infinite; transform-style: preserve-3d; } @keyframes spin3d { to { transform: rotateY(360deg); } } .logo-wrap { animation: levitate 5s ease-in-out infinite; } @keyframes levitate { 50% { transform: translateY(-16px); } } Step 3 — Perspective wrapper Wrap the <img> in a div with style="perspective:900px"

03

Dark Red Glow Hero

Via Custom CSS (no code): Customize → Edit code → paste into assets/base.css: .shopify-section-hero { background: radial-gradient(ellipse 70% 55% at 50% 62%, rgba(110,6,6,.35) 0%, transparent 60%), #000; } Via Section background: In Customize → select hero section → Color scheme → set to darkest option → Background: #000000 The key: Use a pure black PNG as hero image with the CSS gradient layered over it for the blood-red atmospheric glow.

04

Colors & Typography

Customize → Colors: Background #000000 Accent / Buttons #8c1212 Text Primary #ede7de Text Secondary #7a7068 Customize → Typography: Headings: Cormorant Garamond Body: Jost Both are free in Shopify's font library — search by name in the font picker. Display (nav/labels): Syncopate — add via Google Fonts in Custom Liquid header.

05

Product Setup

For each fragrance: Title: NOCTURNE ROUGE Vendor: Velum Fragrances Tags: dupe inspired-by fall-winter Metafields (free via Shopify Admin): custom.inspired_by → "Baccarat Rouge 540" custom.top_notes → "Saffron, Jasmine, Amber" custom.longevity → "12–14 hours" Variants: 30ml / 50ml / 100ml with separate prices. Enables upsell without any app.

06

Zero-Code Dark Mode

Fastest path (15 minutes): 1. In Dawn, go to Customize → Color schemes 2. Edit all 4 default schemes to black backgrounds 3. Set every section to use the darkest scheme 4. In Buttons section → set to #8c1212 crimson Result: 90% of the dark aesthetic with zero custom code — pure Shopify admin. For grain overlay (the film texture): Add a full-width Custom Liquid section at the top with a fixed-position SVG noise texture div. One block of HTML, no app needed.

Brand System

Voice & Visual Guidelines

Brand Voice

Tone: Dark · Poetic · Minimal · Confident Never use exclamation marks, hype words, or slang.
Always: short sentences. Dramatic pauses. Weight.

✓ DO: "This is not a scent. It is a statement."
✗ DON'T: "You'll LOVE this amazing fragrance!!"

Power words:
  • Shadow, depth, quiet, weight, intensity
  • Conjure, whisper, presence, magnetic
  • Underground, deliberate, unspoken

Typography

Display / Labels: Syncopate Bold — all-caps, wide tracking
Headlines: Cormorant Garamond — literary, elegant, italic for warmth
Body: Jost Light (200–300 weight) — airy and modern

Rules:
  • Headlines: Light/Regular only — never Bold
  • Product names: ALL CAPS serif
  • Labels: uppercase + 0.35–0.55em letter-spacing
  • Body line-height: 1.9–2.1

Photography Direction

Backgrounds: Pure black or #050202
Lighting: Single hard side-light with deep shadows
Props: Black obsidian, dark velvet, smoke, red candles
Color grade: Desaturated + deep red shadow tones

Avoid:
  • White or bright backgrounds
  • Lifestyle / outdoor imagery
  • Smiling faces or casual energy
  • Competing saturated colors
